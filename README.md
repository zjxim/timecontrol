# 时间觉察 (Time Awareness)

24小时不间断的状态追踪 App — 让时间可见，提升自驱力。

## 功能

- **状态机系统**：7种状态（学习/工作/娱乐/运动/社交/睡眠/其他），24小时不间断记录
- **切换摩擦力**：学习/工作→娱乐需要长按3秒+确认，对抗冲动切换
- **时间负债**：设定每日学习目标，不足自动累计
- **状态惯性检测**：切换时显示历史平均时长和最长时长
- **惰性对抗模式**：连续娱乐超1小时触发提醒
- **微启动**：只做5分钟，克服启动阻力
- **学习回顾**：离开学习状态时记录所学内容，形成知识库
- **历史日历**：月历视图，可快速跳转到任意日期
- **PWA支持**：可添加到手机主屏幕，支持离线

## 技术栈

纯前端 PWA（Progressive Web App），数据存储在本地 IndexedDB，不上传服务器。
